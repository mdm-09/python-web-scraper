# Python Web Scraper

A lightweight Python web scraper built using `requests` and `BeautifulSoup` to extract book data from a sandbox e-commerce site.

## Features
- Extracts book title, price, and star rating
- Automatically exports structured data directly to a CSV file

## Tech Stack
- Python 3.13
- BeautifulSoup4
- Requests

## How to Run
1. Install dependencies and run the script:
```bash
pip install requests beautifulsoup4
python Scraper.py
```
